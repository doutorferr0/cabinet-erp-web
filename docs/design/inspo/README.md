## Direção geral extraída da coleção

**"Papel funcional"** — o ERP como documento impresso bem diagramado: fundo tintado de papel (nunca branco puro), 1 cor de destaque por contexto, réguas/bordas fortes separando blocos, numerais tabulares, densidade de comanda, status como carimbo. NÃO copiar: textura envelhecida, ilustração decorativa, ornamento, baixo contraste.
